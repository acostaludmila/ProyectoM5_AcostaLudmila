# AURELLE

**Clothing · Jewelry · Essentials**

AURELLE is a fashion e-commerce application developed as the Integrative Project for Henry's Frontend module.

## Tech stack

- React 18
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Context API
- Firebase
- AWS S3
- Vercel

## Development principles

- Mobile-first responsive design
- Strict TypeScript
- Feature-based architecture
- Semantic design tokens
- Light and dark themes
- Files limited to 75 lines whenever possible
- Clear separation of responsibilities

## Current status

Initial application bootstrap and project configuration.
